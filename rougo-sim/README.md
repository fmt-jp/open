# 老後資金シミュレーター（v0.1）

生活費・旅行・車の買い替えなど、周期がバラバラな収支を「いつもの単位」のまま入力するだけで、
年齢ごとの資産残高に自動変換し、老後資金がいつまで持つのかをグラフでひと目で確認できる
Webアプリです。

サーバー不要・ブラウザだけで動作します。GitHub Pages などの静的ホスティングにそのまま公開できます。

## ファイル構成

```
rougo-sim/
├── index.html      … 画面構造（入力タブ／結果タブ）
├── css/
│   └── style.css   … デザイン（配色・タイポグラフィ・レイアウト）
├── js/
│   └── app.js       … 入力状態の管理、計算ロジック、グラフ・表の描画、保存機能
└── README.md
```

外部依存は Google Fonts（Shippori Mincho / Noto Sans JP）と Chart.js（グラフ描画）のみで、
どちらも CDN 経由で読み込みます。ビルド work（npm install など）は不要です。

## ローカルでの起動方法

`index.html` を直接ブラウザで開くだけでも動作しますが、ブラウザによっては
`file://` 経由での挙動に制限がある場合があるため、簡易サーバーでの起動を推奨します。

```bash
cd rougo-sim
python3 -m http.server 8000
# その後ブラウザで http://localhost:8000 を開く
```

Node.js がある場合は次のようにも起動できます。

```bash
npx serve .
```

## GitHub Pages への公開方法

1. GitHub 上に新しいリポジトリを作成します（例：`rougo-sim`）。
2. このフォルダの中身（`index.html` / `css/` / `js/` / `README.md`）をリポジトリの
   ルートに配置し、コミット・プッシュします。

   ```bash
   git init
   git add .
   git commit -m "老後資金シミュレーター v0.1"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```

3. GitHub のリポジトリ画面で `Settings` → `Pages` を開きます。
4. 「Build and deployment」の `Source` を `Deploy from a branch` にし、
   ブランチを `main`、フォルダを `/ (root)` に設定して保存します。
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。

## 使い方の概要

1. 「入力」タブで基本設定（年齢・資産・退職金）を入力します。
2. 「＋収入を追加」「＋支出を追加」から、年金・生活費・旅行・車の買い替えなどを
   普段使う単位のまま登録します（例：生活費 30万円・毎月／車 300万円・5年ごと）。
   「周期（年）」の欄は、周期が「N年ごと」のときだけ入力でき、それ以外
   （毎月・毎年・一時支出）を選んでいる間はグレーアウトして入力できません。
3. 必要であれば「詳細設定」で物価上昇率・運用利回りを調整します（初期値：各2.0%）。
4. 「この内容で試算する」を押すと、「結果」タブに年齢別の資産残高グラフ、
   サマリーカード、年齢別の詳細表が表示されます。
5. 「データを保存…」を押すと、5つの保存枠（スロット1〜5）から保存先を選ぶ画面が開きます。
   空きの枠、または上書きしたい枠を選んで「決定」を押すと保存されます
   （既にデータがある枠を選んだ場合は上書き前に確認が入ります）。
   「データを読み込む…」でも同様に、5つの枠から読み込みたいデータを選べます
   （空きの枠は選択できません）。
   これとは別に、入力中の内容はブラウザに自動で下書き保存されており、
   次回同じブラウザでアクセスした際に自動的に復元されます。
   「初期状態に戻す」を押すと、現在編集中の内容がサンプル値にリセットされます
   （保存済みのスロットのデータは消えません）。

## 計算ロジックの考え方

- 計算単位は1年です。各年齢について「年間収入」「年間支出」「年間収支」「年末資産」を
  順番に積み上げていきます。
- 月額の支出は自動的に12倍して年額に変換します。「N年ごと」の支出は、開始年齢を起点に
  N年おきに発生させます。「一時支出」は指定した年齢にだけ発生します。
  → ユーザーが自分で年額換算する必要はありません。
- 支出額は、物価上昇率にもとづいて現在の年齢を基準に毎年複利で増加します
  （個々の項目ごとに物価上昇率を設定する必要はありません）。
- 資産残高には、設定した運用利回りぶんの運用益（前年末残高 × 利回り）を毎年加算します。
- 退職金は、退職年齢の年の収入として1回だけ加算されます。

## 更新履歴

- v0.1.2：保存機能を「5つの保存枠（スロット）から選んで保存・読み込みできる」方式に
  変更しました。「データを保存…」「データを読み込む…」を押すと、スロット1〜5の
  一覧（空き／保存日時）が表示され、保存先・読み込み元を選べます。上書き時は
  確認ダイアログが表示されます。あわせて、収入の周期選択で「一時支出」ではなく
  「一時収入」と表示されるように修正しました。
- v0.1.1：収入・支出の入力行で、「周期（年）」欄を周期が「N年ごと」のとき
  だけ入力可能にし、それ以外（毎月・毎年・一時支出）のときはグレーアウトして
  入力不可にしました（以前は欄ごと非表示にしていましたが、レイアウトの
  ずれを避けるため常時表示＋無効化に変更）。

## 既知の制約・今後の拡張（v0.2以降）

- 現在は1つのシナリオのみを試算する構成です。「完全退職」「再雇用」などの
  複数シナリオを同じグラフ上で比較する機能は v0.2 以降で追加予定です。
  `js/app.js` の `runSimulation()` はシナリオ単位で独立して呼び出せる構造にしてあるため、
  複数の `state` を保持して結果を配列で `renderChart()` に渡す形に拡張しやすくなっています。
- 収入・支出は万円単位、整数円未満は丸めて表示しています。
- 入力値の保存はブラウザ単位（LocalStorage）です。他の端末やブラウザとは共有されません。
  また、ブラウザの閲覧履歴・サイトデータを消去すると、保存したスロットも失われます。
- 保存スロットは5つ固定です。6つ目以降を保存したい場合は、既存のいずれかの枠を
  選んで上書きしてください。
